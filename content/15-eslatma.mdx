## Kundalik buyruqlar

| Amal | Buyruq |
|---|---|
| Kunni boshlash | `git fetch origin` |
| Yangi tiket | `git switch -c <N>-<slug> --no-track origin/dev` |
| Holat | `git status -sb` |
| Tanlab qo'shish | `git add -p` |
| Commit | `git commit` |
| Dev bilan yangilash | `git fetch origin` va `git rebase origin/dev` |
| Conflict'dan keyin | `git add <fayl>` va `git rebase --continue` |
| Rebase'ni bekor qilish | `git rebase --abort` |
| Birinchi push | `git push` |
| Rebase'dan keyin push | `git push --force-with-lease --force-if-includes` |
| PR ochish | `gh pr create --base dev` |
| Mening commit'larim | `git log origin/dev..HEAD` |
| Mening diff'im | `git diff origin/dev...HEAD` |
| Yo'qolgan commit | `git reflog` |
| Xato commit'ni qaytarish | `git revert <sha>` (yangi branch'da) |

## Qaysi protocol

Ishni boshlashdan oldin protocol'ning saralash jadvalidan belgini toping va o'sha karta bo'yicha ishlang (UM-01). Mos karta bo'lmasa — to'xtang va release owner'dan so'rang (UM-02).

| Vaziyat | Protocol |
|---|---|
| Yangi g'oya yoki xato xabari | YANGI → SPEC |
| Tiketni boshlash | BOSH → COMMIT → MOS → PUSH |
| PR, review, merge | PR → REVIEW → JAVOB → MERGE → TOZA |
| Migratsiya, pul, rol, CI, env, ADR | XAVF |
| Beta'ga, prod'ga chiqarish | PROMOTE → RELIZ |
| Beta qizil, prod buzildi | BETA, PROD, REVERT |
| Sir oshkor bo'ldi, git chalkashdi | SIR, GIT |

## Eng ko'p kerak bo'ladigan bandlar

- **taqiq** — himoyalangan branch'da commit, rebase, force-push (UM-T2, COMMIT-T1).
- **taqiq** — sir, `.env`, shaxsiy ma'lumotni commit qilish (COMMIT-T2).
- **taqiq** — PR matnida `Closes` (PR-T1).
- **majburiy** — bitta tiket — bitta branch — bitta PR (BOSH-01, PR-01).
- **majburiy** — push'dan oldin lokal tekshiruv (PUSH-02).
- **majburiy** — xavfli PR: risk label, release owner merge qiladi (XAVF-01, XAVF-03).
- **majburiy** — qizil beta o'sha kuni yashil (BETA-01).
- **tavsiya** — PR 400 qatordan kichik (PR-08); review bir ish kunida (REVIEW-01).
